## 目前形成的 RPGMap 目标方向（非冻结、非实现）

1. `RPGMapBuilder` 在 Map Subsystem 内组装，`RPGMapHandler` 提供命令／快照／事件，Runtime 唯一持有地图及角色状态；Map 消费调用方提供的逻辑 Content，不创建 FSDB 或跨 Subsystem 另造路由。
2. 新 FSDB 保留 Map／Tileset／MapTransfer／Graphics 方向；独立 `[struct]MapAction` 从**目标协议**取消，Map 内使用少量内置 `kind` 行为声明，Ledge 从 Tile 和 `terrain_tags` 推导。当前代码仍读取旧 MapAction，迁移前不得删除旧脚本安全的 `opaqueRelated` fail-closed 语义。
3. `[struct]NPC` 存复用定义；`[group]MapNPC` 以地图 ID 为 Key 存 JSONL 实例。定义与实例身份独立，FSDB 是初始内容，当前位移等状态由 Runtime 持有；行 Schema、碰撞和跨图生命周期尚待定。
4. Player/NPC 共用 4×4 方向行走图（下／左／右／上），帧宽高分别为 PNG 解码宽高 / 4，不固定总分辨率；以格子底部对齐，视觉尺寸不决定默认 1×1 逻辑占格。

唯一当前设计资料：[RPGMap 设计](https://github.com/lithdoo/loom-realm/blob/main/game-libs/map/todo_docs/RPG_MAP_GENERIC_MODULE_DESIGN.md) · [实体数据调查](https://github.com/lithdoo/loom-realm/blob/main/game-libs/map/todo_docs/ESSENTIALS_V21_1_ENTITY_DATA_INVESTIGATION.md) · [Player/NPC 素材调查](https://github.com/lithdoo/loom-realm/blob/main/game-libs/map/todo_docs/PLAYER_NPC_SPRITE_AND_MOTION_INVESTIGATION.md)。
